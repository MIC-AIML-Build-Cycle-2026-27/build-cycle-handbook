## Phases

The cycle moves through six phases. Each review checks the two phases before it.

| Phase | Goal | Checked at |
|---|---|---|
| 1. Foundation | Scope agreed, architecture drafted, repository and tooling set up, tasks on the board | Review 1 |
| 2. Proof of Concept | The core idea works in a minimal form | Review 1 |
| 3. Core Build | Main components built properly | Review 2 |
| 4. MVP | Main components connected; core workflow works end to end; first results | Review 2 |
| 5. Integration & Evaluation | System integrated and hardened; tested; evaluated against the agreed method | Final Review |
| 6. Finalisation | Documentation, deployment where applicable, demo prepared | Final Review |

Project Leads decide how the time inside each phase is split for their team (weekly targets, internal checkpoints).

## Approximate time available

| Period | Duration |
|---|---|
| Start → Review 1 | ~3.5 weeks |
| Review 1 → Review 2 | ~7 weeks |

The gap between Review 2 and the Final Review is short and includes the holiday period. Plan evaluation and documentation work early rather than leaving it for January.
